# Easy Equb · landing page

Built on the design base in `designbaseforee` (the "Take Control" kit). The UI/UX flow, design tokens, shapes and motion language are kept. All content is Easy Equb.

## Run it
Open `index.html` in a browser, or serve the folder (`python3 -m http.server`). No build step.

## Files
- `index.html` · all ten sections
- `styles.css` · tokens, components, responsive rules
- `script.js` · reveal, menu, tabs, FAQ, draw demo, cookie notice
- `assets/` · your EQ logo (transparent mark, app icon, favicon) and Figtree

## How the base maps to Easy Equb
| Base section | Easy Equb version |
|---|---|
| Nav pill + language + Download | Same, with the EQ logo and a language menu |
| Hero: phone + orbiting group cards | Easy Equb home screen + orbiting equb cards (daily, weekly, monthly...) |

## Design kit rules kept
Figtree, `#eaeae7` background, `#fff` surfaces, `#121211` text, pill buttons, 17px/32px corners, 2px drawn edges, sentence-case headings, no exclamation marks. Accents: Easy Equb red `#e50000` and app teal `#1d5557`.
